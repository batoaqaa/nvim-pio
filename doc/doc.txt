==============================================================================
NVIM-PIO                                                             *nvimpio*

A lightweight manager for PlatformIO Core within Neovim.

`nvim-pio` is a cross-platform Neovim plugin designed to bridge PlatformIO
toolchains with the `clangd` Language Server smoothly. It handles asynchronous
build environment extractions, synchronizes complex board hardware macro
definitions, and intercepts and corrects non-standard compiler argument
diagnostics.

`nvim-pio` automates the installation and environment configuration of
PlatformIO. It ensures that the `pio` executable is available in your 
Neovim session's PATH regardless of your system's global configuration.

CONFIGURATION                                                 *nvimpio-config*

To initialize the plugin, invoke the setup call inside your configuration
scripts frame. 

Minimal Initialization Example:
>lua
  require('nvimpio').setup({
    pio = {
      pio_runtime_dir = '~/.platformio',
      pio_storage_dir = '~/.platformio',
    },
    clangd = {
      support = true,
      install = false,
    },
    menu_key = '<leader>\\',  -- Replace this menu key to your convenience
    menu_name = 'PlatformIO', -- Replace this menu name to your convenience
  })
<

USAGE                                                        *nvimpio-commands*

Commands:

:Pioinit                                                            *:Pioinit*
    Open Neovim in a fresh directory, run `:Pioinit`, and follow the prompt to
    initialize a project. A telescope picker will appear for selecting
    the board, and then another for choosing the framework.
    Press enter to complete the initialization.
    Mapped to: |<leader>\i|

:PioInstall                                                      *:PioInstall*
    Downloads the official PlatformIO installer and sets up a virtual 
    environment in `~/.platformio/penv` asynchronously. 
    Mapped to: |<leader>\pi|

:PioUpgrade                                                      *:PioUpgrade*
    Upgrades the official PlatformIO to the latest release.
    Mapped to: |<leader>\pu|

:PioRepair                                                        *:PioRepair*
    Repair/reinstall PlatformIO      Mapped to: |<leader>\pr|

:Piorun [arg]                                                        *:Piorun*
    Builds, cleans, or uploads your code. If no argument is provided, 
    it defaults to building the active environment. Piorun = 'pio run '
    Examples:
        `:Piorun`           Mapped to: |<leader>\gb|
        `:Piorun build`     Mapped to: |<leader>\gb|
        `:Piorun clean`     Mapped to: |<leader>\gc|
        `:Piorun upload`    Mapped to: |<leader>\gu|
        `:Piorun buildfs`   Mapped to: |<leader>\fb|
        `:Piorun uploadfs`  Mapped to: |<leader>\fu|

:Piocli [cmd]                                                        *:Piocli*
    Run arbitrary PlatformIO commands inside a floating terminal window.
    If no command argument is provided, it opens an interactive terminal prompt
    at your project root folder. Note: the `pio` prefix word is omitted.
    Piocli = 'pio '
    Examples:
       `:Piocli`                     Mapped to: |<leader>\c|
       `:Piocli run -e uno -t upload`
       `:Piocli device list`         Mapped to: |<leader>\gd|

:Piolib [libname]                                                    *:Piolib*
    Search and install libraries interactively. A telescope picker
    displays matches; pick one and press enter to install.
    Examples:
       `:Piolib arduino json`
       `:Piolib keyboard`

:Piomon [baud_rate][port]                                               *:Piomon*
    Open the serial monitor communications shell. Specify a baud rate
    as an optional argument. If omitted, it falls back to 9600 or the
    rate defined inside your local `platformio.ini` file.
    Examples:
       `:Piomon`                     Mapped to: |<leader>\m|
       `:Piomon 9600 COM40
    Mapped to: |<leader>\m|

:PioCompileDB                                                  *:PioCompileDB*
    Generates a localized compilation database (`compile_commands.json`).
    Mapped to: |<leader>\ab|

:PioDbFixPaths                                                *:PioDbFixPaths*
    Forcefully rewrites target references inside `compile_commands.json` to
    resolve cross-platform host mapping path shifts.

:PioGitIgnore                                                  *:PioGitIgnore*
    Launches an interactive menu framework to easily toggle files or 
    folders inside your repository's `.gitignore` file. 
    Mapped to: |<leader>\pg|

:PioDeviceList                                                *:PioDeviceList*
    Scans and lists all active microcontroller hardware serial devices
    connected to your machine along with descriptions.
    Mapped to: |<leader>\gd|

:PioSelectPort                                                *:PioSelectPort*
    Launches an interface selection picker to map specific serial ports 
    and customize configuration flags for upload and monitor routines.

:PioPickEnv                                                      *:PioPickEnv*
    Launches a telescope option selection panel to change your active 
    PlatformIO environment target framework. 
    Mapped to: |<leader>\e|

:PioDebug                                                           *:PioDebug*
    Launches the default integrated PlatformIO hardware debugger using GDB.
    Mapped to: |<leader>\ad|

:ClangdFilter                                                  *:ClangdFilter*
    Launches an interactive dropdown checklist selection menu to mask or block
    unwanted diagnostic errors or warnings emitted by clangd.
    Mapped to: |<leader>\b|

:ClangdFormatterPick                                    *:ClangdFormatterPick*
    Launches an interactive dropdown configuration picker to generate standard
    code style rules (like LLVM, Google, or Mozilla) to a `.clang-format` file.

:ClangdCheckArgs                                            *:ClangdCheckArgs*
    Validates flags and handles real-time stripping of incompatible cross-compiler 
    arguments that can trigger standard desktop language server crashes.

:Clangdrestart                                                *:Clangdrestart*
    Forcefully restarts the active `clangd` LSP language server client instance.
    Mapped to: |<leader>\s|

==============================================================================
INTERACTIVE VIEW CONTROL                                   *nvimpio-interface*

When you open the `:ClangdFilter` menu checklist row view panel, items will display
with their live status markers:

  `[*] Restore Code:  [no_member]`   ➔ Suppressed warning code (Blocked from view)
  `[ ] Suppress Code: [unused-includes]` ➔ Active diagnostic code (Visible on screen)

- Select any row item to toggle its binary state cleanly in RAM.
- Select `💥 Reset All Filters` to purge all local workspace rules instantly.
- Press `<Esc>` to commit choices, flush variables to disk, and re-lint.

STATUSLINE COMPONENTS                                     *nvimpio-statusline*

Integrate the status string tracking hook safely within your configuration.

lualine.nvim configuration snippet:
The implementation utilizes a safe execution proxy wrapper block to guarantee
the editor UI never crashes if the statusline redraws before `lazy.nvim` completes
its initialization loops:
>lua
  sections = {
    lualine_x = {
      function()
        local ok, statusline = pcall(require, 'nvimpio.statusline')
        if ok and type(statusline.get_status_string) == 'function' then
          return statusline.get_status_string()
        end
        return ""
      end,
      'filetype'
    }
  }
<
