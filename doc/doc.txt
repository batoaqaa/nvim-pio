*nvimpio.txt  PlatformIO Toolchain Integration & Clangd Optimizer

==============================================================================
NVIM-PIO                                                             *nvimpio*

A lightweight manager for PlatformIO Core within Neovim.

nvim-pio is cross-platform Neovim plugin designed to bridge PlatformIO
toolchains with the `clangd` Language Server smoothly. It handles asynchronous
build environment extractions, synchronizes complex board hardware macro
definitions. Also, intercepts and corrects non-standard compiler argument
diagnostics.

nvim-pio automates the installation and environment configuration of
PlatformIO. It ensures that the `pio` executable is available in your 
Neovim session's PATH regardless of your system's global configuration.

CONFIGURATION                                                 *nvimpio-config*

To initialize the plugin, invoke the setup call inside your configuration
scripts frame. This registers the Early Lifecycle Invalidation Seeder hooks
and routes your network stream diagnostic traffic patterns natively.

Minimal Initialization Example:
>lua
  require('nvimpio').setup({
    pio = {
      pio_runtime_dir = '~/.platformio',
      pio_storage_dir = '~/.platformio',
    },
    clangd = {
      support = true,
      install = false,
    },
    menu_key = '<leader>\\', -- replace this menu key  to your convenience
    menu_name = 'PlatformIO', -- replace this menu name to your convenience
  })

USAGE                                                        *nvimpio-commands*

Commands:

:Pioinit                                                     *:Pioinit*
    Open Neovim in a fresh directory, run `:Pioinit`, and follow the prompt to
    initialize a project. A telescope picker will appear for selecting
    the board, and then another for choosing the framework.
    Press enter to complete the initialization.

:PioInstall                                                      *:PioInstall*
    Downloads the official PlatformIO installer and sets up a virtual 
    environment in `~/.platformio/penv`. This runs asynchronously.

:checkhealth pio                                            *:checkhealth-pio*
    Runs a diagnostic suite to ensure Python, the core directory, and 
    the `pio` executable are working correctly.


:ClangdFilter                                                  *:ClangdFilter*
    Launches the interactive dropdown selection picker panel window viewport
    inside your current active code buffer view frame.
    This command key mapped to <leader>\\b
>lua
<

:Piorun [arg]                                  *:Piorun*
    This command builds and uploads the code. Optional arguments: 
    build, upload, clean. If no argument is provided, 
    it defaults to build and upload.
                         Examples:
                            `:Piorun`
                            `:Piorun build`
                            `:Piorun upload`
                            `:Piorun clean`

:Piocli [cmd]                                  *:Piocli*
    Run PlatformIO commands either in float or horizontal direction.
                         Example: `:Piocli device list`.
    The command argument is optional. If not provided, it opens a floating
    toggleterm in the project root where you can execute commands.
    Note: `pio` keyword is not required in the command.
                         Examples:
                            `:Piocli`
                            `:Piocli run -e uno -t upload`
                            `:Piocli device list`
                            `:Piocli boards arduinouno --json-output`

:Piolib [libname]                                  *:Piolib*
    Install a library by providing a keyword for search. A telescope picker
    will show available libraries. Pick one and press enter to install.
                         Examples:
                            `:Piolib arduino json`
                            `:Piolib keyboard`

:Piomon [baud_rate]                                  *:Piomon*
    Open a serial monitor. Specify a baud rate as an
                         optional argument. If not provided, it uses the default
                         baud rate (9600) or the one specified in platformio.ini.
                         Examples:
                            `:Piomon`
                            `:Piomon 115200`

:Piolsserial                                  *:Piolsserial*
    List out all the serial devices connected with their description

:Pidebug                                  *:Piodebug*
    Starts the default PlatformIO debugger with gdb

:PioTermList                                  *:PioTermList
    You can see a list of pio terminals using :PioTermList command in normal mode.
    It is mapped to <leader>pl

INTERACTIVE VIEW CONTROL                                   *nvimpio-interface*

When you open the `:ClangdFilter` menu checklist row view panel, items will display
with their live status markers:

  `[*] Restore Code:  [no_member]`   ➔ Suppressed warning code (Blocked from view)
  `[ ] Suppress Code: [unused-includes]` ➔ Active diagnostic code (Visible on screen)

- Select any row item to toggle its binary state cleanly in RAM.
- Select `💥 Reset All Filters` to purge all local workspace rules instantly.
- Press `<Esc>` to commit choices, flush variables to disk, and re-lint.

STATUSLINE COMPONENTS                                     *nvimpio-statusline*

Integrate the status string tracking hook natively or via modern custom plugins:

lualine.nvim configuration snippet:
>lua
  sections = {
    lualine_x = {
      function() return require("nvimpio.statusline").get_status_string() end,
      'filetype'
    }
  }
<

Native Neovim statusline string assignment:
>lua
  vim.opt.statusline:append("%{v:lua.require('nvimpio.statusline').get_status_string()}")
