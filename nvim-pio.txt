INTRODUCTION                                                   *nvimpio*

A plugin for wrapping PlatformIO commands with user-friendly Neovim commands.

==============================================================================

USAGE                                                    *nvim-pio-usage*

:Pioinit                                                     *:Pioinit*
    Open Neovim in a fresh directory, run `:Pioinit`, and follow the prompt to initialize a project. A telescope
    picker will appear for selecting the board, and then
                         another for choosing the framework. Press enter to
                         complete the initialization.

:Piorun [arg]                                  *:Piorun*
            This command builds and uploads the code. Optional
                         arguments: build, upload, clean. If no argument is
                         provided, it defaults to build and upload.
                         Examples:
                            `:Piorun`
                            `:Piorun build`
                            `:Piorun upload`
                            `:Piorun clean`

:Piocli [cmd]                                  *:Piocli*
       Run PlatformIO commands either in float or horizontal direction.
                         Example: `:Piocli device list`.
                         The command argument is optional. If not provided, it
                         opens a floating toggleterm in the project root where
                         you can execute commands. Note: `pio` keyword is not
                         required in the command.
                         Examples:
                            `:Piocli`
                            `:Piocli run -e uno -t upload`
                            `:Piocli device list`
                            `:Piocli boards arduinouno --json-output`

:Piolib [libname]                                  *:Piolib*
       Install a library by providing a keyword for search. A
                         telescope picker will show available libraries. Pick
                         one and press enter to install.
                         Examples:
                            `:Piolib arduino json`
                            `:Piolib keyboard`

:Piomon [baud_rate]                                  *:Piomon*
     Open a serial monitor. Specify a baud rate as an
                         optional argument. If not provided, it uses the default
                         baud rate (9600) or the one specified in platformio.ini.
                         Examples:
                            `:Piomon`
                            `:Piomon 115200`

:Piolsserial                                  *:Piolsserial*
		List out all the serial devices connected with their
			description

:Pidebug                                  *:Piodebug*
		 Starts the default PlatformIO debugger with gdb

:PioTermList                                  *:PioTermList
             You can see a list of pio terminals using :PioTermList
                         command in normal mode. It is mapped to <leader>pl

CONFIGURATION                                        *nvim-pio-configuration*

The plugin exposes a few configuration options that can be set in your
`setup()` call.

clangd_source                                          *nvim-pio-clangd_source*

    This plugin relies on clangd as the LSP. `Compiledb` used to collect
    all configuration used for compilng the project and also used for `clangd.

    .clangd file created in cwd and platformio core directory. Also toolchain
    compilers bin path extracted to populate clangd cmd with query-driver and
    also to included in environment path to fix the issue taht compiledb keeps
    compiler names only in their commands not with absolute path.
